>

>
> 記録はその Mac の中（`~/.mamori/`）だけに保存されて、外部には送りません。イヤになったらアプリをゴミ箱に入れるだけで消せます。

## 送る文面（くわしい版）

> セキュリティ点検アプリ「守（まもり）」を配布しています。
>
> **何をするの？**
> Mac のメニューバーに常駐して、その Mac の設定（画面ロック、ファイアウォール、共有設定、暗号化など）に穴がないかを毎日チェックします。安全に直せるものは自動で直し、締め出しや再起動のおそれがある危ない項目は勝手に直さず「承認すれば直せる」として教えてくれます。守りの強さが 0〜100 の点数でわかります。
>
> **点数はこう見てください**
> - 90以上 = とても良い
> - 75以上 = 良い
> - 60以上 = ふつう
> - 40以上 = 注意
> - 40未満 = 要対応
>
> **使い方（4ステップ）**
> 1. ダウンロード → https://mamori.teai.io/MamoriBar.zip
> 2. `MamoriBar.zip` をダブルクリックで展開し、出てきた `MamoriBar.app` を「アプリケーション」フォルダへ移す
> 3. アプリを**右クリック →「開く」→「開く」**（初回だけ。Apple の公証を受けていないため、この手順が必要です）
> 4. メニューバー右上に盾のアイコンが出ます。クリックすると点数と内訳が見られます
>
> **「あと1ステップで使えます」と出たら**
> 点検には Apple の「コマンドラインデベロッパツール」を使います。入っていない Mac では、アプリが**「開発者ツールを入れる」**ボタンを出すので、押して案内に従い、数分待って「再確認」を押すだけです。無料です。ターミナルは開かなくて大丈夫。
>
> **プライバシー**
> 点検の記録はその Mac の中（`~/.mamori/`）にだけ保存され、外部には送信しません。アプリを消したいときは「アプリケーション」から `MamoriBar.app` をゴミ箱へ。
>
> **うまくいかないとき**
> - 「開発元を確認できません」で開けない → 右クリック →「開く」→「開く」。それでもだめなら「システム設定 → プライバシーとセキュリティ → 画面下の『このまま開く』」
> - 点数が出ない → 初回は1〜2分かかります。一度アプリを終了して開き直してみてください
>
> くわしい手順 → https://mamori.teai.io/start#mac

## 送る人向けの補足（自分用メモ）

- 対応 OS: macOS 13 以降（Apple Silicon / Intel 両対応）
- 配布物サイズ: 約 165KB（点検エンジン同梱・追加インストール不要）
- 初回だけ Gatekeeper の許可が必要（公証なしのため）。将来 Apple Developer Program の証明書を入れて公証すれば、この手順は不要になる
- 点検エンジンは Python 標準ライブラリのみで動作。外部送信なし
- 開発者ツールが無い Mac では、アプリ内のボタンから `xcode-select --install` を起動できる
