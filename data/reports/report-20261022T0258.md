### CVE-2026-96656 — Plex Media Server: Plex Media Server External Control of File Name or Path Vulnerability
- [緊急] CVE-2026-96656 は悪用確認済み。CISA対応期限: 2026-10-23
- 【plex】具体的対策:
-   - Plex Media Server のバージョン確認: 設定 → サーバー → 一般 で現在バージョンを確認

- CISA指定の対応（一般）: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage
