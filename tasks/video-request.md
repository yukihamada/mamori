# Mamori 説明動画の制作依頼（Claude Code へ）

## 目的
Mamori（mamori.teai.io）が「なぜ必要か」を、優貴さんの声と動画で説明する60〜90秒の動画を作る。

## 背景（今回の実績・動画の核になる話）
- 2026-10-23、自分の公開サービス（Fly.io上の複数アプリ）のログを調べたら、攻撃は既に来ていた
  - /info.php・/phpinfo へのphpinfo探索
  - React Server Components脆弱性の悪用試行（rsc_exploit_attempt、FlyのWAFがブロック）
  - 難読化PHPバックアップファイル探索（/Trnity.php.bakup）
- これらをMamoriに初めて共有し、観測0→3件になった
- さらに fly logs を巡回して攻撃パターンを自動検出→Mamoriに共有するツール tools/fly-watch.py を作った
- 統計学者と批判者の討論の結論：「安全になった」の統計的証明は不可能。だからMamoriは効果を約束せず「最新の脅威が6時間ごとに届き、照合できる」という機能と正直さで勝負する

## メッセージ
- 攻撃は「来てないかも」ではなく「見えてないだけ」。中小こそ狙われる
- 1社の観測がみんなの防御になる。Mamoriは匿名で共有できる
- 効果の過剰な約束はしない。正直に、無料で、6時間ごとの脅威情報と照合キットを提供

## 要件
- 声: 優貴さんの声（KOE）。~/.claude/guides/koe-tts.md に従う
- 尺: 60〜90秒、1080p MP4、字幕付き
- 構成: ①「攻撃、来てないと思ってませんか？」②実際に来ていた3つの例 ③Mamoriで共有・照合 ④正直な約束（効果の証明はしない、でも情報と照合は無料で届く）
- 出力: ~/workspace/mamori/media/mamori-first-share.mp4 と .jpg
- 非公開の試聴版を作り、本人の確認後に公開
- 制作費は累計500クレジット以下の既存承認の範囲で進める
